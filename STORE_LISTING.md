# Japanese Walk Store Copy

## Short Description

Japanese-style interval walking with clear fast/slow phases, section progress, and saved workout recording.

## Full Description

Japanese Walk is a simple interval walking app for Garmin watches inspired by Japanese interval walking training.

The workout alternates between fast and slow walking blocks and keeps the session readable at a glance with a large countdown timer, a phase icon, and a section ring around the edge of the watch face.

During the workout, the app shows:

- Remaining time in the current phase
- Total workout time
- Distance
- Heart rate
- Calories
- Section progress

When the workout is saved, the app records a FIT activity as `Japanese Walk`. On supported watches, GPS is enabled during the workout to improve route and map data.

## Key Features

- Fast and slow interval walking phases
- Large, easy-to-read timer
- Circular section progress ring
- Saved FIT workout recording
- Clean watchface layout for modern Garmin devices

## Permissions Note

- `Fit` is used to save the workout activity
- `Sensor` is used for metrics such as heart rate
- `Positioning` is used to improve route and map recording
